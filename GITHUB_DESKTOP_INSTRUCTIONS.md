# GitHub Desktop Setup - Step by Step

Follow these steps to push your code to GitHub using GitHub Desktop:

## Step 1: Open GitHub Desktop

1. Open GitHub Desktop application
2. Sign in to your GitHub account if prompted

## Step 2: Add Local Repository

1. Click **File** → **Add Local Repository**
2. Click **Choose...** button
3. Navigate to: `C:\Users\Zenbook\Desktop\ms-enerji`
4. Click **Add repository**

## Step 3: Review Changes

1. You'll see all your files listed as changes
2. At the bottom, you'll see a text box for commit message
3. Enter: `Initial commit: MSN Enerji Xidmətləri website - Professional energy audit services website for Azerbaijan`
4. Click **Commit to main** button

## Step 4: Publish to GitHub

1. After committing, you'll see a **Publish repository** button at the top
2. Click **Publish repository**
3. A dialog will appear:
   - **Name**: `msn-enerji-xidmetleri` (or your preferred name)
   - **Description**: `Professional website for MSN Enerji Xidmətləri MMC - Energy audit services in Azerbaijan`
   - **Keep this code private**: Choose based on your preference
4. Click **Publish Repository**

## Step 5: Verify

1. After publishing, GitHub Desktop will show your repository
2. You can click **View on GitHub** to see it on GitHub.com
3. Your code is now on GitHub! 🎉

## Next Steps

After publishing, you can:
- View your repository at: `https://github.com/YOUR_USERNAME/msn-enerji-xidmetleri`
- Set up GitHub Pages for hosting
- Connect to deployment services (Vercel, Netlify, etc.)
- Share the repository with others
